# دليل تشغيل خادم «دليلك الطبي» (Dalilik Al-Tibbi Backend)

هذا هو النظام الخلفي (Backend) وقاعدة البيانات المركزية لتطبيق أندرويد «دليلك الطبي».

---

## 1. المتطلبات الأساسية
- Node.js (الإصدار 18 فما فوق).
- npm أو yarn.

---

## 2. خطوات التثبيت والتشغيل المحلي

1. انتقل إلى مجلد الخادم:
   ```bash
   cd server
   ```

2. ثبّت الحزم:
   ```bash
   npm install
   ```

3. أنشئ ملف البيئة `.env` من النموذج:
   ```bash
   cp .env.example .env
   ```
   يمكنك تعديل بيانات المدير وكلمة المرور في ملف `.env`:
   ```env
   PORT=5000
   JWT_SECRET=your_super_secret_jwt_key
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=AdminSecurePassword2026!
   ```

4. شغّل سكريبت إنشاء حساب المدير الأولي (Seed):
   ```bash
   npm run seed
   ```

5. ابدأ تشغيل الخادم:
   ```bash
   npm start
   ```
   سيعمل الخادم على: `http://localhost:5000` أو `http://10.0.2.2:5000` لمستخدمي محاكي الأندرويد.

---

## 3. نقاط الاتصال (API Endpoints)

### أولاً: النقاط العامة (للمستخدمين والجمهور)
- `GET /api/health`: فحص حالة الخادم واتصاله بقاعدة البيانات.
- `GET /api/doctors/meta/summary`: إحصائيات سريعة (عدد الأطباء، التخصصات، المحافظات، تاريخ آخر استيراد).
- `GET /api/doctors`: البحث عن الأطباء مع دعم المعايير:
  - `q`: نص البحث (الاسم الثلاثي أو جزء منه، يدعم معالجة الألف والياء والتاء المربوطة وإزالة التشكيل).
  - `specialty`: تصفية حسب التخصص.
  - `governorate`: تصفية حسب المحافظة.
  - `page`: رقم الصفحة (افتراضي 1).
  - `limit`: عدد النتائج في الصفحة.
- `GET /api/doctors/:id`: جلب التفاصيل الكاملة لطبيب محدد بما فيها الحقول الديناميكية الإضافية.

### ثانياً: نقاط الإدارة المحمية (تتطلب `Authorization: Bearer <token>`)
- `POST /api/auth/login`: تسجيل دخول المدير واستخراج رمز JWT.
- `GET /api/auth/me`: التحقق من صلاحية جلسة المدير.
- `POST /api/admin/doctors/batch-import`: استيراد دفعة أطباء مع تحديد نمط الاستيراد (`APPEND`، `MERGE`، `REPLACE_ALL`).
- `GET /api/admin/import-history`: استعراض سجل عمليات الاستيراد السابقة.
- `POST /api/admin/doctors`: إضافة طبيب يدوياً.
- `PUT /api/admin/doctors/:id`: تعديل بيانات طبيب.
- `DELETE /api/admin/doctors/:id`: حذف طبيب.
- `GET /api/admin/backup`: تصدير نسخة احتياطية كاملة من قاعدة بيانات الأطباء.

---

## 4. ربط تطبيق أندرويد بالخادم
داخل تطبيق أندرويد:
- من شاشة دخول الإدارة أو الإعدادات، يمكنك تحديد رابط الخادم المركزي (مثلاً رابط السيرفر المنشور على السحابة أو `http://10.0.2.2:5000` للمحاكي).
- يوفّر التطبيق زر "اختبار الاتصال" للتأكد من استجابة الخادم قبل محاولة تسجيل الدخول.
